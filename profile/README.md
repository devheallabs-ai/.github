## Quick Start

```bash
# macOS / Linux
curl -fsSL https://nc.devheallabs.in/install.sh | bash

# Windows (PowerShell)
irm https://nc.devheallabs.in/install.ps1 | iex

# Docker
docker pull devheallabs/nc:v1
```
