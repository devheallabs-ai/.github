## Decision Making

- **Minor changes** (bug fixes, docs, typos): Merged by any maintainer after CI passes.
- **Features and API changes**: Require a GitHub Issue or Discussion first, then a reviewed PR.
- **Breaking changes**: Announced in advance, discussed in GitHub Discussions, released in a new major version.

## Releases

- Releases follow [Semantic Versioning](https://semver.org/).
- Release notes are published on GitHub Releases.
- All releases are tagged and signed.
